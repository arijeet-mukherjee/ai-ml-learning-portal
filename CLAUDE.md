# ml-learning-portal

Personal ML/AI learning portal for the IIT Kharagpur PG Certificate in ML & AI.

- **Adding or editing course content?** Read `ADDING_NEW_MODULES.md` first. Content is
  typed data in `src/content/`, never JSX. Core components and the renderer stay untouched.
- **Where every fact comes from:** `SOURCE_NOTES.md`. Do not introduce a number that
  cannot be traced to a file listed there.
- **Next.js 16 gotchas:** `NEXTJS_16_NOTES.md`, and `AGENTS.md` for the general rule.
